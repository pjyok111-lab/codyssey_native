## 미해결 1. 제80회 심화 3번 선지 ③ 탑의 이름 알아내기

- 모델: Claude Opus 5.5 (유료 요금제)
- 문제 사진: [q03.png](images/q03.png)
- 해설지 기준 정답: ③ 고려 경천사지 10층 석탑
- 원하는 결과: 수험생이 오답 선지가 무엇인지 알 수 있도록, ③ 탑의 이름과 시대를 맞게 알려 주기
- 네 번 시도했지만 ③의 이름은 한 번도 맞히지 못했다. ②(발해 영광탑)는 네 번째 시도에서 맞혔으므로 여기서는 ③만 다룬다.

### 시도한 프롬프트

#### 시도 1. 모델 비교 프롬프트 (2026-11-20 15:50, 사진 5장 첨부)

```
첨부한 사진 5장은 한국사능력검정시험 심화 제80회 1~5번 문제입니다.
문제마다 아래 형식으로 답해 주세요.

1. 정답 번호
2. 문제가 요구하는 답
3. 정답 선지가 나타내는 것
4. 오답 선지가 나타내는 것 (오답 선지마다 한 줄씩)
```

#### 시도 2. 시스템 프롬프트 v1, 예시 없음 (2026-11-20 16:40, q03.png 첨부)

[system-design 3-1](system-design.md)의 시스템 프롬프트 v1 전문 뒤에 아래 줄을 붙여 보냈다.

```
첨부한 사진은 한국사능력검정시험 심화 제80회 3번 문제입니다. 풀어 주세요.
```

#### 시도 3. 시스템 프롬프트 v1 + 예시 3개 (2026-11-20 16:43, q03.png 첨부)

시도 2의 프롬프트에서 마지막 줄 바로 앞에 [system-design 4절](system-design.md)의 예시 3개를 끼워 넣어 보냈다.

#### 시도 4. 프롬프트 v2, 탑만 콕 집어 질문 (2026-11-20 17:24, q03.png 첨부)

[system-design 8-2](system-design.md)의 프롬프트 v2 전문에서 마지막 줄 '이 문제 풀어 주세요.'를 아래 줄로 바꿔 새 대화에서 보냈다.

```
②, ③ 탑의 이름과 시대를 알려 주세요.
```

### 받은 결과

| 시도 | ③에 대한 답 (원문에서 옮김) | 결과 |
|---|---|---|
| 1 | 백제 탑이 아닙니다. 고려 시대 평창 월정사 팔각 구층 석탑으로 보이지만, 사진만으로는 확실하지 않습니다. | 이름이 틀림 (추측) |
| 2 | 회색의 가늘고 높은 다층 석탑입니다. 고려 시대 탑으로 보이지만, 어떤 탑인지는 확실하지 않습니다. | 이름을 대지 못함 |
| 3 | 정확히 어떤 탑인지 확실하지 않습니다. | 이름을 대지 못함 |
| 4 | 아래 원문 | 이름을 대지 못함 |

시도 4의 답 원문:

```
② 발해 영광탑으로 보입니다.

시대: 발해
근거: 벽돌로 쌓은 5층 전탑이고, 1층에 아치형 출입구가 있습니다. 영광탑은 이런 모습으로 한능검 발해 문제에 자주 나옵니다.

③ 이름은 확실하지 않습니다.

층수가 많고 가늘고 높은 모습이라 고려 시대 다층 석탑일 가능성이 있습니다. 하지만 사진만으로는 어떤 탑인지, 어느 시대인지 단정하기 어렵습니다.
시험 해설지나 문제집 정답지에서 ③의 이름을 확인해 주세요.
```

### 막힌 이유 (직접 작성)

2를 맞춘 것도 사실 운이라고 생각하고, 3도 계속 시도하다 보면 맞출 수 있다고 생각은 해. 다만 사진 문제는 아직 맞추는 데 있어서 한계가 큰 것 같다고 생각이 돼. 프롬프트 문제가 아니라 사진을 인식하고 비교하는 능력 부족 문제라고 생각해. 수험생이 쓸 때 사진이 선지에 들어간 문제의 경우에는 해설지를 따로 찾아봐서 그 부분만 체크하는 게 필요하다고 생각돼.

## 미해결 2. 제80회 심화 13번 선지 ② 유물의 이름 알아내기

- 모델: Claude Opus 5.5 (유료 요금제)
- 문제 사진: [q13.png](images/q13.png)
- 해설지 기준: 정답 ④. ① 칠지도, ② 농경문 청동기, ③ 호우명 그릇, ⑤ 금동대향로
- 원하는 결과: 정답뿐 아니라 오답 선지 유물이 무엇인지 알려 주기
- 두 번 시도해 ①(칠지도)과 ⑤(금동대향로)는 두 번째 시도에서 맞혔다. ②(농경문 청동기)는 끝내 이름을 대지 못했고, ③(호우명 그릇)은 두 번 모두 이름은 맞혔지만 '확실하지 않다'며 확신하지 못했다. 여기서는 ②와 ③의 확신 문제를 다룬다.

### 시도한 프롬프트

#### 시도 1. 프롬프트 v2 (2026-11-20 17:35, q13.png 첨부)

[system-design 8-2](system-design.md)의 프롬프트 v2 전문을 그대로(마지막 줄 '이 문제 풀어 주세요.') 새 대화에서 보냈다.

#### 시도 2. 프롬프트 v2, 유물만 콕 집어 질문 (2026-11-20 17:40, q13.png 첨부)

프롬프트 v2 전문에서 마지막 줄 '이 문제 풀어 주세요.'를 아래 줄로 바꿔 새 대화에서 보냈다.

```
①, ②, ③, ⑤ 유물의 이름과 시대를 알려 주세요.
```

유물 이름만 물었지만, 답은 v2의 문제 풀이 형식(정답 번호부터)으로 나왔다.

### 받은 결과

#### 시도 1의 답 원문

```
정답 번호: ④
문제가 요구하는 답: 버드나무 등 물가 풍경을 청동 표면에 은입사 기법으로 새긴 고려의 금속 공예품, 청동 은입사 포류수금문 정병입니다.
정답 선지가 나타내는 것: ④ 청동 은입사 포류수금문 정병 → 고려
오답 선지가 나타내는 것:
① 확실하지 않습니다.
② 확실하지 않습니다.
③ 신라 호우총에서 나온 호우명 그릇(고구려 광개토 대왕 이름이 새겨진 청동 그릇)으로 보이지만, 사진만으로는 확실하지 않습니다.
⑤ 확실하지 않습니다.
```

#### 시도 2의 답 원문

```
정답 번호: ④
문제가 요구하는 답: 은입사 기법으로 버드나무 등 물가 풍경을 새긴 고려의 금속 공예품, 청동 은입사 포류수금문 정병입니다.
정답 선지가 나타내는 것: ④ 청동 은입사 포류수금문 정병 → 고려
오답 선지가 나타내는 것:
① 칠지도 → 백제
② 확실하지 않습니다. 사진만으로는 유물 이름과 시대를 판단하기 어렵습니다.
③ 확실하지 않습니다. 경주 호우총에서 나온 호우명 그릇(신라 무덤 출토, 고구려 광개토 대왕 관련 글자 새김)일 수 있지만, 사진만으로는 단정하기 어렵습니다.
⑤ 금동 대향로 → 백제
```

#### 시도별 비교

| 선지 | 해설지 | 시도 1 | 시도 2 |
|---|---|---|---|
| ① | 칠지도 | 확실하지 않음 | 칠지도 (맞힘) |
| ② | 농경문 청동기 | 확실하지 않음 | 확실하지 않음 |
| ③ | 호우명 그릇 | 호우명 그릇으로 보이나 확실하지 않음 | 호우명 그릇일 수 있으나 단정 어려움 |
| ④ (정답) | 정답 | ④ | ④ |
| ⑤ | 금동대향로 | 확실하지 않음 | 금동 대향로 (맞힘) |

### 막힌 이유 (직접 작성)

일부는 맞추는데, 2번만큼은 끝까지 못 맞추네. 3번도 맞는데 확신이 없다고 하고. 내 생각에 형태가 명확하고 유명한 유물은 맞출 수 있는데, 좀 덜 유명한 유물은 끝내 못 맞추는 것 같아. 사진 문제의 경우에는 이렇게 비교적 실루엣의 형태가 명확한 유물 문제에서도 사용하는 데 있어서 한계가 있다는 것이 잘 드러나는 문제였어.
