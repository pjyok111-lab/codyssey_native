## 5. Zero-shot과 Few-shot 비교

<!-- 같은 문제를 예시 없이 한 번, 예시를 넣고 한 번 시킨 결과를 비교한다. -->

- 모델: Claude Opus 5.5 (유료 요금제)
- 방법: 대화를 새로 열 때마다 첫 메시지에 시스템 프롬프트 v1과 문제 사진(q03.png)을 함께 보냄. Few-shot은 v1의 마지막 요청 줄 바로 앞에 4절의 예시 3개를 끼워 넣음

| 항목 | Zero-shot 결과 (2026-11-20 16:40) | Few-shot 결과 (2026-11-20 16:43) |
|---|---|---|
| 사용한 문제 | 제80회 심화 3번 | 제80회 심화 3번 |
| 정답 여부 | ④ 정답 | ④ 정답 |
| 형식 준수 | 정답을 제목으로 뺀 뒤 나머지를 1~3번으로 다시 번호 매김. 요청하지 않은 '풀이 요령'을 덧붙임 | 4항목 형식과 번호를 그대로 지킴. 끝에 한 문장을 덧붙임 |
| 길이 | 선지마다 특징 설명이 붙어 김 | 선지마다 '→ 시대' 한 줄로 짧음 |
| 모르는 선지 처리 | ②를 '보은 법주사 팔상전으로 보입니다'라고 추측한 뒤 확실하지 않다고 덧붙임(해설지 기준 ②는 발해 영광탑으로 추측이 틀림). ③은 '고려 시대 탑으로 보이지만' 확실하지 않다고 함 | ②, ③ 모두 추측 없이 '정확히 어떤 탑인지 확실하지 않습니다'라고만 함 |

- 달라진 점: Few-shot을 넣자 형식이 예시와 같아지고 답이 짧아졌으며, Zero-shot에서 나온 '추측한 이름 + 확실하지 않음' 대신 추측 없이 모른다고만 답했다.
- 단계적 추론 유도를 더했는가: 아니오. 짧고 핵심만 제시해주는 답을 원하는데, 단계적 추론 유도를 더하면 답의 가독성이 떨어질 것 같아.

#### Zero-shot 답 원문 (2026-11-20 16:40)

```
## 정답: ④

**1. 문제가 요구하는 답**
(가)는 **백제**입니다. 근거는 "제25대 왕인 무령왕"입니다. 무령왕은 백제의 왕이고, 무령왕릉은 공주 송산리에 있습니다. 따라서 백제의 문화유산을 고르는 문제입니다.

**2. 정답 선지가 나타내는 것**
④ **익산 미륵사지 석탑**: 백제 무왕 때 세운 탑입니다. 목탑 양식을 돌로 옮긴 형태이고, 한쪽이 무너져 계단처럼 보이는 모습이 특징입니다.

**3. 오답 선지가 나타내는 것**
- ① **경주 불국사 다보탑**: 통일 신라 때 탑입니다. 복잡한 구조와 기둥, 돌사자가 특징입니다.
- ② **보은 법주사 팔상전**으로 보입니다(조선 후기, 목조 5층). 다만 사진만으로는 **확실하지 않습니다.**
- ③ 회색의 가늘고 높은 다층 석탑입니다. 고려 시대 탑으로 보이지만, 어떤 탑인지는 **확실하지 않습니다.**
- ⑤ **경주 분황사 모전 석탑**: 신라 선덕 여왕 때 탑입니다. 돌을 벽돌 모양으로 다듬어 쌓았고, 기단 모서리의 돌사자가 특징입니다.

**풀이 요령:** ②·③을 몰라도 "무령왕 → 백제 → 미륵사지 석탑"만 연결하면 정답을 고를 수 있습니다. 백제 탑으로는 미륵사지 석탑과 **부여 정림사지 오층 석탑** 두 개를 함께 외워 두세요.
```

#### Few-shot 답 원문 (2026-11-20 16:43)

```
1. **정답 번호: ④**

2. **문제가 요구하는 답:** 무령왕릉을 남긴 나라, 즉 25대 왕 무령왕이 다스린 **백제**의 문화유산입니다.

3. **정답 선지가 나타내는 것:**
④ 익산 미륵사지 석탑 → 백제 무왕 때 세운 탑

② 정확히 어떤 탑인지 확실하지 않습니다.
③ 정확히 어떤 탑인지 확실하지 않습니다.
⑤ 경주 분황사 모전 석탑 → 신라 선덕 여왕 때 세운 탑

②와 ③은 이름을 확인하지 못했지만, 백제 탑인 ④가 분명하게 보이므로 정답을 고르는 데는 영향이 없습니다.
```

### 8-3. v2에서 고친 내용과 이유 (직접 작성)

- 고친 내용:
  1. [지켜야 할 규칙]에 '주어진 형식을 정확히 따른다. 항목 번호, 항목 이름, 쌍점(:)을 임의로 바꾸거나 빼지 않는다'를 더함
  2. [답하는 형식]의 항목마다 쌍점(:)을 붙여, 따라야 할 형식을 예시와 똑같이 보여 줌
  3. [지켜야 할 규칙]에 '형식 밖의 문장은 덧붙이지 않는다(되묻는 경우는 예외)'를 더함
- 고친 이유: 주어진 형식 대로 정확히 안 출력해주면 나중에 출력값을 정리할 때 혼선이 생길 수도 있으니까, 쌍점 같이 사소한 것도 임의적으로 수정하지 않도록 하는 것이 좋다고 생각함.
- 겨냥한 실행 로그 지점: 환각과 문맥 끊김이 나타나지 않아, 대화에서 지시와 가장 어긋난 응답을 골랐다.
  - 턴 2, 4, 6, 8, 10: 예시와 달리 '정답 선지가 나타내는 것', '오답 선지가 나타내는 것' 뒤의 쌍점(:)을 뺌
  - 턴 10: 형식 앞뒤에 안내 문장 두 줄('방금 푸신 5번 문제와 같은 사진이에요. 답은 같습니다.', '다른 문제를 보내려던 거라면 그 사진을 다시 보내 주세요.')을 덧붙임
- 개선 확인: v2로 새 대화를 열어 1번과 5번(두 번)을 다시 풀게 한 결과, 쌍점이 모두 붙었고 같은 사진을 다시 보내도 형식 밖 문장을 덧붙이지 않았다 (run-log 3-1절).
