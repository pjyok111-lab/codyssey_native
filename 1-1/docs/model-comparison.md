## 3. 비교에 쓴 프롬프트

### 모델 A, B (사진 5장 첨부)

```
첨부한 사진 5장은 한국사능력검정시험 심화 제80회 1~5번 문제입니다.
문제마다 아래 형식으로 답해 주세요.

1. 정답 번호
2. 문제가 요구하는 답
3. 정답 선지가 나타내는 것
4. 오답 선지가 나타내는 것 (오답 선지마다 한 줄씩)
```

### 모델 C (사진 1장 첨부)

```
첨부한 사진 1장은 한국사능력검정시험 심화 제80회 1~5번 문제입니다.
문제마다 아래 형식으로 답해 주세요.

1. 정답 번호
2. 문제가 요구하는 답
3. 정답 선지가 나타내는 것
4. 오답 선지가 나타내는 것 (오답 선지마다 한 줄씩)
```

### 입력 조건 차이

GPT-6 무료 요금제는 한 번에 사진을 3장까지만 첨부할 수 있어서, 문제 사진 5장을 이미지 한 장([q01-q05-merged.png](images/q01-q05-merged.png))으로 합쳐 첨부하고 프롬프트의 '5장'을 '1장'으로 바꿨다. 합친 사진은 문제 하나하나가 작게 보이므로, 모델 C의 사진 판독 오류에는 이 조건 차이가 영향을 주었을 수 있다.

## 4. 비교 기준

1. 정답률: 5문제 가운데 공식 정답과 같은 번호를 고른 문제 수
2. 형식 준수: 요청한 4항목(정답 번호, 문제가 요구하는 답, 정답 선지가 나타내는 것, 오답 선지가 나타내는 것)을 지켰는지, 요청하지 않은 내용을 덧붙이지 않았는지
3. 오답 해설 충실도: 오답 선지 4개를 빠짐없이, 무엇을 나타내는지 밝혀 설명했는지
4. 해설 속 사실 오류: 정답 번호는 맞아도 해설에 틀린 사실(유물 이름, 시대, 인물, 연도, 선지 인용)이 섞였는지
